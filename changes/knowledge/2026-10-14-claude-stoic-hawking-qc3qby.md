* **Update**: [Mildenhall's aggregate package](/references/aggregate-mildenhall.md), from `prospicio_prob::Discrete` (P&L PR 1, branch claude/stoic-hawking-qc3qby): `make_var_tvar`'s equal-mass test is `np.isclose` with its default relative tolerance 1e-5, and `tvar` on a lone atom raises an `IndexError`; `Discrete` matches it on 544 values.
* **Update**: [Mildenhall's aggregate package](/references/aggregate-mildenhall.md), from the P&L ledger kernel (P&L PR 2, branch claude/stoic-hawking-qc3qby): `PnL` normalizes the source once and its rows keep those probabilities; a second normalization moves a cumulative that equals a ladder level across a quantile's jump. The ledger matches the kernel on 1,704 values.
* **Update**: [Mildenhall's aggregate package](/references/aggregate-mildenhall.md), from rebucketed legs and the ratio exhibit (P&L PR 3, branch claude/stoic-hawking-qc3qby): a leg's `bs` changes only `economic_marginal_df`; `summary_df`'s quantiles, the moments and `κ` stay on the exact values. A `PnL` built with `role=` names its one group after the ledger, which labels its ratio row. Matched on 324 values.
* **Update**: [Mildenhall's aggregate package](/references/aggregate-mildenhall.md), from the builders for annual covers (P&L PR 4, branch claude/stoic-hawking-qc3qby): in DecL `cede 10%` after a deposit is a 10% ceding commission, not a share; a DecL ledger normalizes over the engine's whole grid, zeros included, so its probabilities differ in the last bit from a sum over the atoms with mass; the consolidated face rebuckets the net onto the grid, which can move `κ75` across a tie. Matched on 2,401 values.
