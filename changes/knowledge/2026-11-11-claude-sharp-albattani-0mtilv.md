* **Update**: [where CI's time went](/environment/ci-runtime.md), from #848 to #851 (branch claude/sharp-albattani-0mtilv): four processes on a four-core runner made the NUTS-heavy binding tests three to five times slower whatever the rayon thread count, so the python and r jobs now run in legs on runners of their own (light files on four workers, the slow files serially, the guides alone); `cargo test` with line tables only took 303 to 392 s against 483 s; the python job went from 19.5 to about 9 minutes and the r job from 13 to about 8.5.
* **Update**: [local checks](/environment/local-checks.md), from #849 (branch claude/sharp-albattani-0mtilv): `cargo xtask r` and CI run the R files through `validation/scripts/run_r_tests.py`, which reports every failed file instead of stopping at the first.
