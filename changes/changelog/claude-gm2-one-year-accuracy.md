### Reserving

- **Behaviour change:** compartmental model 2's one-year view (`Compartmental::one_year`, `one_year_segments`; Python `Compartmental.one_year`, `one_year_segments`; R `compartmental_one_year()`, `compartmental_model_2_one_year()`, `compartmental_one_year_segments()`) now refits its flagged simulations with a light refit by default, so it is slower and accurate by default. `BayesOneYear::light_refit` (`LightRefit`; Python `light_refit=` and R `light_refit =`) is a shorter NUTS run scaled by the opening posterior: model 2's totals come within about 0.03 sd of full refits on company 337 at about a thirtieth of their cost, but 2,000 simulations take about 31 minutes on 16 threads, against 85 s when reweighted only, which was the default before (about 0.4 sd off a refit). Turn it off with `BayesOneYear::no_light_refit`, Python `light_refit=False` or R `light_refit = FALSE` (reweight only, with the approximate warning), or set `n_sims` or `max_refits` to bound the time. Model 1 and the other Bayesian models are unchanged (#394).
